📊 Data Visualization Project — Week 6 Capstone
🚀 Overview
This repository contains four visualization challenges designed to strengthen skills in Matplotlib, Seaborn, Plotly, and storytelling dashboards. The project covers static charts, interactive reports, and visualization critique/redesign.

✅ Task 1: Multi-Chart Visualization Notebook
Goal: Create at least 6 chart types using a real dataset (Titanic, Iris, or ETL dataset).

Charts Implemented
Bar chart (Matplotlib)

Line chart (Matplotlib)

Histogram (Matplotlib)

Scatter plot (Matplotlib)

Box plot (Seaborn)

Heatmap (Seaborn)

Requirements:

Proper titles, axis labels with units

1-sentence insight caption beneath each chart

At least 4 charts with Matplotlib, 2 with Seaborn

Deliverables:

Jupyter notebook (multi_chart_visualization.ipynb)

6 charts with captions

📊 Task 2: Storytelling Dashboard (Subplot Grid)
Goal: Build a 2×2 subplot figure that tells a cohesive story.

Steps Implemented
Dataset with ≥3 numeric and ≥2 categorical columns

2×2 subplot grid with consistent color palette

Shared legends and annotations

Export at 300 DPI

Narrative summary (3 sentences) at the top of notebook

Deliverables:

Jupyter notebook (storytelling_dashboard.ipynb)

Subplot grid image (dashboard.png)

🌐 Task 3: Interactive Plotly Report
Goal: Recreate charts as interactive equivalents with Plotly Express.

Steps Implemented
Recreate 3 Matplotlib charts in Plotly

Add custom hover data (≥2 columns)

Color-encode categorical variable

Export each chart as standalone HTML

Build 4th interactive chart type not covered in class (e.g., choropleth, sunburst, treemap)

Document design choices in code comments

Deliverables:

Jupyter notebook (plotly_report.ipynb)

3 interactive charts (chart1.html, chart2.html, chart3.html)

4th advanced chart (extra_chart.html)

📝 Task 4: Visualization Critique + Redesign
Goal: Critically evaluate poor real-world charts and redesign them.

Steps Implemented
Find 2 poorly designed charts online (news, research, Kaggle).

Document 3 design flaws for each chart.

Recreate charts in Python with fixes applied.

Write before/after comparison explaining changes.

Deliverables:

Jupyter notebook (visualization_critique.ipynb)

Original chart embeds

Redesigned charts (redesign1.png, redesign2.png)

Written critique and comparison
